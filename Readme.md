# 🛒OneCart : E-Commerce Website (MERN)

## 📂 Project Structure
- **Frontend** – User shopping website
- **Admin** – Admin dashboard
- **Backend** – REST API & database

## 🧑‍💻 Tech Stack
- React
- Node.js
- Express.js
- MongoDB
- Razorpay
- JWT Authentication

## ✨ Features
- User & Admin Authentication
- Product Management
- Cart & Checkout
- Online Payments
- Order Management

## ▶️ How to Run Locally

### Backend
cd backend
npm install
npm start

### Frontend
cd frontend
npm install
npm start

### Admin
cd admin
npm install
npm start
